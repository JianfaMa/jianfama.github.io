Projects

  • AirHunt: Bridging VLM Semantics and Continuous Planning for Efficient Aerial Object Navigation

    Developed a real-time aerial navigation system for large-scale unknown outdoor environments driven by natural language commands, bridging high-latency VLM reasoning with low-latency UAV control for zero-shot object navigation.

    • Decoupled slow VLM inference from fast UAV replanning via dual-pathway asynchronous architecture.
    • Achieved 78% navigation success rate in AirSim and validated on custom-built quadrotor across 10+ hours of outdoor real-world experiments.
    • Contribution: Designed high-frequency geometric path planner, low-frequency VLM semantic reasoning module, and ROS-based cross-module communication.
  • RoGaussianOCC: Accurate and Robust Gaussian Occupancy Prediction in Autonomous Driving

    Built a robust 3D Gaussian occupancy prediction model for vision-based autonomous driving, tackling random Gaussian initialization, occlusion from single-frame inference, and sparse supervision signals.

    • Proposed temporal Gaussian propagation and 4D Gaussian sampling to aggregate history frames and reduce occlusion.
    • Achieved 32.20% IoU and 20.65% mIoU on nuScenes (+7.95% / +8.12% over baseline).
    • Contribution: Propose and implement full framework; conduct model training, parameter tuning, ablation studies, and visualization.
  • Natural Language Instructions Based 3D Cross-Modal Perception System for UAVs

    Developed a generalized embodied UAV agent leveraging VLMs for natural language instruction and environmental interaction.

    • Integrated RGB-D + SLAM for 3D point cloud mapping and 3D-LLMs for cross-modal Q&A and object detection.
    • Contribution: Trained and fine-tuned 3D-LLM for interaction tasks; fine-tuned VLM for waypoint generation; developed and deployed ROS system on UAV.
